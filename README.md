# Portfolio Foundation

This project provides the initial Astro foundation for a scalable, editorial portfolio website.

## Structure

- src/components for reusable UI and layout components
- src/layouts for page layout wrappers
- src/pages for route entry points
- src/content for markdown and settings-driven content
- src/styles for global design tokens and styles
- src/lib and src/data for shared logic and content data
